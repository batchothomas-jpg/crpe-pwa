# CRPE Révisions

Application web progressive de révision, déployée sur GitHub Pages.

## Contenus

- Fiches et quiz de mathématiques, français et autres domaines du CRPE.
- Préparation à l’écrit de français organisée selon les chapitres d’un manuel 2024-2025 : fiches synthétiques, quiz expliqués, pistes pour l’oral et sujets blancs originaux.
- Préparation à l’admission : didactique, conception de séances, évaluation, différenciation, développement de l’enfant, EPS, motivation et situations professionnelles.
- Entraînements originaux en français et mathématiques, avec corrigés indicatifs.
- Les banques de questions enrichissent aussi les examens aléatoires.

Les fiches, questions et sujets ajoutés sont rédigés pour cette application ; ils ne reproduisent pas les exercices ni les corrigés des ouvrages sources.

## Attention aux sessions et aux voies

Les ouvrages utilisés correspondent à des éditions et sessions différentes : guide d’admission 2025, manuel de français 2024-2025 et annales écrites de 2022. Le format externe bac+3 organisé depuis 2026 est différent ; le bac+5 est maintenu à titre transitoire pour 2026 et 2027. Les modalités d’admission 2027 ont également été modifiées. Toujours vérifier les épreuves, durées, programmes et textes applicables à la voie et à la session préparées.

- [Épreuves officielles du CRPE externe bac+3](https://www.devenirenseignant.gouv.fr/les-epreuves-du-concours-externe-bac3-de-recrutement-de-professeurs-des-ecoles-1380)
- [Épreuves officielles du CRPE externe bac+5](https://www.devenirenseignant.gouv.fr/les-epreuves-du-concours-externe-bac-5-de-recrutement-de-professeurs-des-ecoles-1009)
- [Arrêté modificatif applicable à partir d’octobre 2026](https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000054861950)

## Déploiement

Le projet est configuré pour GitHub Pages, avec son chemin de base `/crpe-pwa/`. Aucun fichier de configuration Netlify n’est nécessaire pour le déploiement actuel.
